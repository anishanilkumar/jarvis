# Bundled fonts

Self-hosted rather than fetched from a CDN: a wall panel that loses its typeface
when the internet drops is not offline-capable. Only the Latin subsets are here,
which is why they total ~68 KB.

Both are licensed under the **SIL Open Font License 1.1**, which permits
redistribution alongside this project. Neither is covered by the repository's
MIT licence.
